ปัญหาที่เจอบ่อยที่สุดมีอยู่สองอย่าง อย่างแรกคือสมัครเสร็จแล้วเพิ่งนึกได้ว่าลืมใส่รหัสแนะนำ ซึ่ง **แก้ทีหลังไม่ได้** ต้องสมัครใหม่ด้วยอีเมลใหม่ อย่างที่สองคือไม่รู้ว่าต้องทำ KYC ก่อนหรือเปล่า และฝากเงินบาทเข้าไปได้จริงไหม

บทความนี้เรียงตามลำดับที่คนสมัครใหม่ต้องเจอจริง ตั้งแต่เช็คเงื่อนไขก่อนเปิดหน้าเว็บ ไปจนถึงจ่ายค่าธรรมเนียมเทรดครั้งแรก

## เช็ค 4 อย่างก่อนเปิดหน้าสมัคร

ข้ามขั้นนี้ไปแล้วมักต้องย้อนกลับมาแก้ทีหลัง

**1. อีเมลหรือเบอร์โทรที่ยังไม่เคยใช้กับ Gate** หนึ่งอีเมลหรือหนึ่งเบอร์โทรใช้สมัครได้บัญชีเดียว ถ้าเคยสมัครไว้แล้วแต่จำไม่ได้ ระบบจะแจ้งว่าซ้ำ และคุณจะไม่สามารถ "เริ่มใหม่" ด้วยข้อมูลเดิมได้

**2. ประเทศหรือภูมิภาคที่พำนัก** ตอนสมัครต้องเลือกจริง ๆ เพราะผลิตภัณฑ์ ตัวกฎหมาย และขั้นตอนยืนยันตัวตนของแต่ละประเทศไม่เหมือนกัน บางภูมิภาคอย่างสหราชอาณาจักรถูกจำกัดการใช้บริการบางส่วน และ Gate ไม่ให้บริการกับพื้นที่ที่ถูกคว่ำบาตร ถ้าเลือกประเทศที่ให้ข้อมูลไม่ตรงกับเอกสารยืนยันตัวตน KYC จะไม่ผ่านอยู่ดี

**3. เอกสารยืนยันตัวตน** ใช้ได้ทั้งบัตรประชาชน พาสปอร์ต หรือใบขับขี่ เลือกอย่างใดอย่างหนึ่ง และต้องเป็นชื่อเดียวกับที่กรอกในระบบ

**4. รหัสผ่านที่จำได้จริง** อย่างน้อย 8 ตัวอักษร และควรมีตัวเลขกับตัวพิมพ์ใหญ่ผสม แนะนำให้ตั้งรหัสที่ไม่ซ้ำกับเว็บอื่น เพราะ Gate ไม่มีระบบ "กู้บัญชีด้วยเบอร์โทร" แบบธนาคาร

> ถ้ายังไม่มั่นใจว่าจะเทรดจริงหรือเปล่า ลองเปิดบัญชีทดลอง (Demo) ก่อนได้ ใช้เงินปลอมสูงสุด 0.1 BTC หรือ 1,000 USDT เล่น合约ได้ถึง 125 เท่าโดยไม่ต้องผ่าน KYC แต่โหมดนี้ไม่มี Earn ไม่มี P2P และถอนอะไรไม่ได้เลย

## KYC: ทำเมื่อไหร่ ใช้เวลานานแค่ไหน

การยืนยันตัวตน หรือ KYC ไม่ใช่ของแถม แต่เป็นด่านที่ต้องผ่านก่อนฝาก ถอน และเทรดจริง ถ้าเน้นเข้าไปดูหน้าตลาดอย่างเดียวจะยังใช้ได้ แต่พอต้องใช้เงินจริงระบบจะล็อกไว้

สิ่งที่ต้องเตรียม:

- ประเภทบัญชี (บุคคล หรือ บริษัท) — คนทั่วไปเลือกบุคคล
- ข้อมูลส่วนตัวตามที่หน้าจอถาม ชื่อ-นามสกุลต้องสะกดตรงกับเอกสาร
- รูปเอกสารยืนยันตัวตน มักรับไฟล์ jpg หรือ png ขนาดไม่เกิน 3 MB
- การยืนยันใบหน้า หรืออัปโหลดรูปตามท่าที่ระบบกำหนด ถ้ากล้องหน้าโน้ตบุ๊กใช้ไม่ได้ ให้ทำผ่านแอป Gate บนมือถือ

Gate แยก KYC เป็นหลายระดับ ระดับแรกคือข้อมูลส่วนตัวกับรูปบัตร ระดับถัดไปเพิ่มที่อยู่และรูปถ่ายยืนยันตัวตน ระดับสูงสุดคือหลักฐานที่อยู่ ซึ่งช่วยเพิ่มวงเงินถอนให้สูงขึ้นอีก

เรื่องเวลาตรวจ เอกสารของ Gate ระบุว่าการยืนยันตัวตนมักใช้เวลา 1–3 วันทำการ บางเคสผ่านในไม่กี่ชั่วโมง แต่ถ้าข้อมูลไม่ตรงกับเอกสารจะค้างรอนานกว่านั้น และไม่มีทางลัดให้กดข้าม

> เอกสารปลอมหรือชื่อที่สะกดไม่ตรงกับบัตรจะทำให้การยืนยันล้มเหลวทันที และบางกรณีบัญชีถูกระงับ อย่าลองเสี่ยง

ระหว่างรอ KYC อนุมัติ ใช้เวลานั้นตั้งค่าความปลอดภัยให้ครบก่อนดีกว่า

## ตั้งค่าความปลอดภัยทันทีหลังสมัคร

บัญชีที่ไม่มี 2FA คือบัญชีที่รอวันถูกขโมย สามอย่างนี้ทำได้ในหน้าเดียวกัน

- **ผูก Google Authenticator** ใช้เป็นด่านที่สองตอนล็อกอิน แม้รหัสผ่านรั่วก็ยังเข้าไม่ได้
- **ตั้งรหัสผ่านการเงิน (Fund Password)** แยกจากรหัสล็อกอิน ใช้ยืนยันตอนเทรดและถอน — ห้ามตั้งซ้ำกัน
- **เปิดรหัสป้องกันฟิชชิงและ whitelist ที่อยู่ถอน** อีเมลจาก Gate ทุกฉบับจะมีรหัสนี้ ถ้าไม่มีให้ถือว่าปลอมทันที ส่วน whitelist กันคนที่เข้าบัญชีคุณได้จากการย้ายเงินออกไปที่อยู่ใหม่

Gate ย้ำกับผู้ใช้เสมอว่าเจ้าหน้าที่จะไม่ขอรหัสผ่าน 2FA หรือ private key จากคุณไม่ว่ากรณีใด ถ้ามีใครอ้างตัวแบบนั้นใน Telegram หรือ LINE ถือว่าเป็นมิจฉาชีพทั้งหมด

ถ้ามีคริปโตอยู่ในกระเป๋าหรือ exchange อื่นอยู่แล้ว การโอนบนเชนคือทางที่ถูกที่สุด แต่ต้องเลือกเครือข่ายให้ตรงกันก่อนส่ง ถ้าส่ง USDT ผิดจาก TRC20 ไปเป็น ERC20 เงินจะหายถาวร ไม่มีฝ่ายสนับสนุนไหนดึงคืนได้

ส่วนคนที่อยากเริ่มจากเงินบาท ให้เข้าไปดูหน้า C2C ของ Gate ก่อน ระบบจะโชว์สกุลเงินท้องถิ่นและช่องทางโอนที่ผู้ขายในแต่ละประเทศรองรับ Gate ระบุว่า P2P ของตัวเองครอบคลุมประมาณ 80 ประเทศกับช่องทางชำระเงินกว่า 450 ช่องทาง และไม่มีค่าธรรมเนียมแพลตฟอร์มทั้งฝั่งซื้อและฝั่งขาย

กลไกของ P2P คือ Gate เป็นคนกลางรับฝากคริปโตไว้ พอคุณเลือกผู้ขายแล้วโอนเงินตามรายละเอียดที่ผู้ขายให้ คุณกด "ชำระแล้ว" ผู้ขายตรวจเงินเข้าจึงปล่อยเหรียญออกมา อย่ากดว่าจ่ายแล้วถ้ายังไม่ได้โอนจริง — เป็นสาเหตุอันดับหนึ่งของข้อพิพาท ผู้ขายที่ผ่านการตรวจจะมีป้ายน้ำเงินหรือมงกุฎให้ดูคร่าว ๆ ได้
